# Pipeline Generator

A visual CI/CD pipeline builder. Add jobs for your frontend, backend, and
database migrations — each with its own framework preset (React, .NET,
Spring Boot, Go, Rails, Laravel, Django, EF Core, Prisma, and more) — edit
the steps, and export a ready-to-use config for GitHub Actions, GitLab CI,
or Jenkins.

## Features

- **Multi-job pipelines** — combine frontend, backend, and database jobs
  (each on its own runtime/language) into a single pipeline
- **Framework presets** — pick a stack and get sensible default steps,
  fully editable afterward
- **Multiple targets** — generate `.github/workflows/ci.yml`,
  `.gitlab-ci.yml`, or a `Jenkinsfile` from the same job list
- **Live preview** — syntax-highlighted output, copy or download the
  generated file

## Getting started

```bash
npm install
npm run dev
```

## Tech stack

React + Vite.
